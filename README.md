# SublimePythonPugin

一些自己写的SublimeText4插件

* compare_python_dicts 
对比两个python字典的差异
* curl_to_requests
将curl代码转为python的requests库代码
* jq_custom_query
jq处理json的语法支持插件
* json_to_dict
将json数据转为python字典格式
* EscapeReplace
忘了是什么功能了
* JsBeautify
js代码格式化.仅按规则进行换行操作. 不检查语法
* JsMinify
使用babel对js进行标准压缩
* MultiCrypto
对字符串进行多种加密
* MultiDecode
对字符串进行多种解密尝试
* UrlFormat
对一个url进行格式化
